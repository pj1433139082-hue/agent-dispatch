# 编排主流程需求问卷（S1）

**Purpose：** 锁定「需求对齐 → 拷问+选型 → 规格 → 拆票 → 实现」这条主流程的功能需求与交付标准，决定 v0.9 要实现什么、哪些点必须你签字。

**From:** lead（AI） · **To:** 你（甲方） · **How your answers will be used:** 直接转成 `to-spec` 的输入，再切成票据执行。

## Context

你提出：把 ask-matt 那套流程做成主线，技术选型交给子 agent 并行做（开源借鉴 / 搜索取证 / 多角色对抗性审查），交付标准在 `to-spec` 阶段和你对齐，最后 `to-tickets` 分人设派活。现在要定的是：**这套流程里哪些地方必须停下来等你说"行"，以及"行"的判据是什么。**

## How to answer

10–20 分钟即可。没想好的写「待定」并说明卡在哪，比空着有用；不确定的直接写「不确定」。
