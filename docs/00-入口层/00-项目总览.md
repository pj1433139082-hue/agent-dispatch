# 项目总览

**派单台 · agent-dispatch** 是一个文件优先的任务编排分发 CLI：把 Markdown 票据变成可执行工单，经过独立验收和异体评审后才允许进入 `done`。当前版本 v0.6，Python 3.11+，运行时只用标准库；v0.6 增加 `dispatch auto`，用外部执行器半自动推进并保留 verify/review/land 门禁。

## 当前状态

- 业务实现：`src/agent_dispatch/`，111 个测试通过；入口 `dispatch`。
- 启动任务：`tasks/kickoff` 记录项目启动规划事实（payload、plan、方案接受记录），已 `completed_locally`；启动任务不等于业务实现验收。
- 仓库：https://github.com/pj1433139082-hue/agent-dispatch ，默认分支 `main`，MIT，public。
- 门禁：CI job `test` 是 `main` 的必需状态检查；PR 实测会先 `BLOCKED`，检查通过后 `CLEAN`。
- DSH：`dispatch dsh push/run/status/outcome/update/archive/delete` 已对本机 50567 看板做过真实创建、触发、回读、重跑、变更与清理探针。

## 边界

v0.6 不做 Web UI、多用户权限、云沙箱、自动 push/合并目标分支，也不内置模型运行时；`auto` 只调用外部命令，负责“票据 → 工单 → 回执 → 验收 → 评审 → 状态/导出/投递/半自动推进”的最小闭环。看板投递不是验收结论，auto 也不绕过 verify/review。阶段与档位以 `task.json` 和 CLI 查询为准，不从本页或聊天推断。
